# Qwen3.8-27B：单张910B2的BF16 LoRA训练基线

2026-10-23，物理2号卡，ms-swift 4.6.0。完成32条训练样本、8次优化器更新和训练前后独立验证，进程正常退出。这证明当前短序列配置可以单卡LoRA微调27B；全参数训练不在本次测试范围内。

## 配置

| 项目 | 实际配置 |
|---|---|
| 模型 | 现有Qwen3.8-27B，Transformers Qwen3_5ForConditionalGeneration |
| 原模型 | BF16，冻结，不量化、不做CPU卸载 |
| LoRA | FP32，rank=4，alpha=16，dropout=0 |
| 目标模块 | q_proj、v_proj、in_proj_qkv；视觉部分冻结 |
| 优化器 | AdamW，学习率1e-4，梯度裁剪1.0 |
| 数据 | GPT-4-LLM的Alpaca GPT4中文数据，固定种子20261023，短样本32训练/8验证 |
| 序列与批量 | 最大128 token，单卡batch=1，梯度累积4，即每次更新4条样本 |
| 训练长度 | 8次更新，训练集一轮 |
| 执行 | 梯度检查点、eager attention、原生Torch GDN回退；未开启swift的NPU模型补丁 |

原有GSM8K评测题没有进入本次训练。按问题去重后分割训练/验证；选择完整短样本而非截断答案。

## 复现与产物

结构化证据：[qwen27b-swift-sft.json](../../evidence/2026-10-23/qwen27b-swift-sft.json)。包含版本、配置、每步loss/梯度范数、显存峰值、数据源校验值、适配器校验值和清理回执。

- [prepare_data.py](prepare_data.py)：从本地Alpaca中文JSON准备32/8划分。需要设置MODEL_DIR和SFT_RUN。
- [train_baseline.py](train_baseline.py)：标准swift入口加检查回调，保存显存和参数更新审计。
- [run_baseline.sh](run_baseline.sh)：配置复现入口。先初始化匹配的CANN环境，并设置MODEL_DIR、SFT_RUN、TRAINING_PYTHON及ASCEND_RT_VISIBLE_DEVICES。将上述两个Python文件及原数据放入独立SFT_RUN，再准备数据、启动训练。会实际占用所选单卡，不应在共享卡繁忙时运行。

原始数据、完整日志、checkpoint及带私有运行路径的参数文件保留在服务器原实验目录；仓库仅记录可移植代码和过滤证据。未将LoRA合并进原模型，未改变推理部署。用户随后要求将训练单独建仓，本轮按该要求整理进独立私有训练仓库并首次提交推送。
