# 最终微批的梯度累积与反向下发重叠：101.28 → 95.74秒

本轮从已选中101.28秒/256条的配置继续，固定global256、每卡micro16、累积8、原样本顺序与padding、BF16计算/累积、CPU FP32主权重及Adam m/v。原权重只读，不改共享安装。

上一轮无采样计时中，每次更新的CPU累积本体约26.1秒，主要可与反向重叠；但最终微批在每个参数处等待CPU累积，主线程累计等待9.66–9.77秒。该等待位于原生norm/FP32卸载之前，阻止后续反向工作及时提交，不能简单视为全部可节省时间。

候选保留每个微批的BF16相加次序与原生归约，仅将最终边界参数登记，待原生reduce epilogue同步生产者、CPU队列排空后，按原梯度就绪顺序执行原生范数和FP32卸载。每个参数只允许一次边界登记，异常即停止；不提前更新参数，不修改全局梯度裁剪或Adam数学。NPU只依次临时放入当前梯度分片，不驻留完整梯度。

## 整模型结果

两rank小模型三次更新的完整FP32梯度/master/m/v逐位核对通过。随后27B使用原768条、三次更新，第四次重复首256条仅采样；首轮冷启动和末轮采样不计入稳态速度。后两轮每轮取较慢rank，95.5825、95.8980秒，平均**95.7402秒/256条**。

相对上一版101.2831秒，耗时降低**5.47%**，每256条少5.54秒；相对最初micro16参考107.9709秒，累计降低约11.33%。本轮没有改变更新频率、样本顺序、有效输入或padding。验证loss **0.8581519723**、正确token **204/224**，与上一版完全一致。短验证和小模型逐位检查不代表整模型长期收敛/位级一致证明。
