# 显存建模 v0

用户提出通过数学模型在上卡前预测显存分项。本轮完成标准库CPU计算器：架构参数精确计数；FFN、非融合RMSNorm、eager注意力、词表损失、临时梯度的形状公式；已观测峰值生命周期15/8组及隐藏状态51/24份单列校准；重算/小项BS比例标明经验，不伪装通用自动liveness。

B16/S256参考模型56.55950/54.05388GiB，实测56.55997/54.05422。未参与校准的旧第二轮全S192，预测49.36949/47.59177，旧实测49.37045/47.59237GiB，误差小于1MiB；不推广为任意配置误差。全部计算只用CPU、未导入torch或加载权重、没有启动NPU任务。原81.22秒入口保持，压缩版不使用。物理HBM额外runtime/allocator开销未知时不输出总量；形状/调度/融合变化可能移动峰值，后续可扩展自动生命周期图和后端workspace规则库。
