# Adam 状态显存研究：最终记录（Stage 1–13）

整理日期：2026-10-24，Asia/Shanghai。这里保存已完成的小规模 CPU 研究，不是新的训练任务；本次提交没有重跑实验、使用 NPU、恢复目标训练或做 CPU 状态卸载。

## 最终结论

1. **严格 FP32 逐位一致、长期持续训练、m/v 替代空间 ≤30 GiB，目前没有同时达成。** 这是现有证据的边界，不是不可能性证明。
2. **允许近似时，直接 4-bit m/v、B128 是待验证候选。** 条件预算约 27.406 GiB（B64 约 29.754 GiB）；这不是目标设备峰值，也不是目标任务同质量证明。近似路线仅为比较研究，不更改当前严格精度约束或授权训练。
3. **有限历史因子重放可以在同一显式算术下逐位一致。** Stage11 的特定 8 步小模型配置为原 m/v 的 8.10%，仅原生 BF16 输入 X 改为 16-bit 存储时为 7.32%。历史随步数/token 增长，不是固定空间长期解法。
4. **成熟实际小 MLP 状态的无损帧约为原始 m/v 的 83%，不是 15%。** Stage13 所测 BF16/低秩预测器加完整残差没有净胜过 byteshuffle+zlib。3.30%/4.82% 仅来自明确构造的 rank-2 对照。

30 GiB 指 m/v 替代预算，不是整套训练峰值。公开 Qwen3.5 文本架构计数为 26,895,998,464 参数：原 FP32 m/v 为 200.390804 GiB，30 GiB 对应 14.97074684%。单份 BF16 文本权重另需 50.097701 GiB；主权重、梯度、激活、通信与运行时另计。公开架构不能认证原仓库另名 checkpoint 的实际配置/张量。
